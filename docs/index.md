## What is Blockfolk?

Blockfolk is a fake-player NPC system for Paper 26.2 servers. Almost all day-to-day administration happens through inventory menus: create a preset, configure it, place one or more instances, then attach routes and behaviour.

The deterministic behaviour system works on its own. AI behaviour is an optional layer for servers that want contextual conversations and model-selected actions.
